# MONI

브라우저에 수입과 지출을 보관하고 분석하는 개인 소비 대시보드입니다. 정적 파일을 GitHub Pages에서 실행할 수 있습니다.

- 기록 추가, 수정, 삭제 및 월·날짜·카테고리 필터
- 월별 지출 흐름, 카테고리 비교, 소비 달력과 기록 기반 요약
- 월별 전체·카테고리 예산 및 앱 내 경고
- 반복 지출, 사용처 추천, CSV 가져오기·내보내기와 JSON 백업

기록은 브라우저의 IndexedDB에만 저장됩니다. 브라우저 데이터를 삭제하거나 기기를 바꾸기 전에 JSON 백업을 저장하세요. 예시 기록은 설정에서 삭제할 수 있습니다. 반복 지출은 앱을 열 때 지난 회차가 등록됩니다. 영수증 OCR과 은행 계좌 연동은 제공하지 않습니다.

## 로컬 실행

`python -m http.server 8000` 실행 후 `http://localhost:8000`으로 접속합니다.

## 검증

`npm ci` 후 `npm test`로 데이터와 주요 입력 동작을 검사합니다. Lucide 아이콘은 MIT 라이선스입니다.
