# MONI

브라우저의 IndexedDB에 기록을 저장하는 개인 소비 분석 웹앱입니다. 정적 파일을 GitHub Pages에 배포할 수 있습니다.

## 사용

홈에서 월별 통계를 확인하고 + 버튼으로 수입·지출을 기록합니다. 설정에서 예산, 반복 지출, CSV 및 JSON 백업을 관리할 수 있습니다. 예시 기록은 설정에서 삭제할 수 있습니다.

데이터는 기기와 브라우저별로 저장되므로 정기적으로 백업하세요. 영수증 OCR과 은행 계좌 연동은 제공하지 않습니다. 반복 지출은 앱을 열 때 등록됩니다. 이 앱은 외부 서버에 금융 기록을 동기화하지 않습니다.

## 로컬 실행

`python -m http.server 8000` 실행 후 브라우저에서 `http://localhost:8000`을 엽니다.
